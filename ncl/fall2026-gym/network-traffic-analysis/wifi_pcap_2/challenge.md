# WiFi PCAP 2

- Category: Network Traffic Analysis
- Difficulty: Medium
- Points: 100

## Description

Crack the WEP key and analyze the second Wi-Fi capture.

## Questions

- How many IVs are there? (20 pts)
- What is the key size in bits? (20 pts)
- What is the first IV in hex? (20 pts)
- What is the WEP key? (20 pts)
- What is the first TCP checksum in hex? (20 pts)
