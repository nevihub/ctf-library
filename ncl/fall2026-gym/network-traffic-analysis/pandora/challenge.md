# Pandora

- Category: Network Traffic Analysis
- Difficulty: Hard
- Points: 100

## Description

Analyze the custom-protocol traffic in the Pandora capture.

## Questions

- What are the server and client IPs? (10 pts)
- What is the server port? (10 pts)
- What is the magic 2-byte ID in decimal? (10 pts)
- How many requests are there? (10 pts)
- What are the first and second request lengths? (10 pts)
- What is the hash size? (10 pts)
- What are the first and second responses in hex? (15 pts)
- What is the hidden flag? (15 pts)
