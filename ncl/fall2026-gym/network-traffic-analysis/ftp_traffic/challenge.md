# FTP Traffic

- Category: Network Traffic Analysis
- Difficulty: Easy
- Points: 100

## Description

Analyze the FTP traffic capture.

## Questions

- What was the first user:pass attempt? (10 pts)
- What is the server software and version? (15 pts)
- What was the first successful user:pass? (15 pts)
- What was the first command? (10 pts)
- What file was deleted? (10 pts)
- What file was uploaded? (15 pts)
- How many bytes were uploaded? (10 pts)
- What was the anonymous download? (15 pts)
