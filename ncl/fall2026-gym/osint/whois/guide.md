# WHOIS — walkthrough summary

_Official Trove guide: https://trove.cyberskyline.com/a60b1f22554d4d66a9a733a787e9df50 (login required)_

## Technique

Run the domain through ICANN's registration lookup (lookup.icann.org) — authoritative for registrar, creation date, and registry ID. The .cloud TLD is managed by Aruba; split the domain right-to-left to isolate the TLD.
