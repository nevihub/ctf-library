# Meta

- Category: osint
- Difficulty: Easy
- Points: 70

## Description

Extract metadata from a photo.

## Questions

- Q1 (10 pts): `Image creation date (round down to nearest minute)`
- Q2 (10 pts): `Image dimensions (e.g. 800x600)`
- Q3 (10 pts): `Camera make`
- Q4 (10 pts): `Camera model`
- Q5 (10 pts): `Exposure time (e.g. 1/200)`
- Q6 (20 pts): `GPS coordinates where the picture was taken`
