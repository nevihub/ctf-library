# The Book

- Category: Forensics
- Difficulty: Hard
- Points: 100

## Description

Analyze a live memory dump taken from a hacker's computer.

## Questions

- What is the operating system? (5 pts)
- What is the computer name? (5 pts)
- Who is the logged-in user? (10 pts)
- What is the file path and file of interest? (10 pts)
- What is the real name of 'cloud'? (30 pts)
- What is the logged-in user's password? (40 pts)
