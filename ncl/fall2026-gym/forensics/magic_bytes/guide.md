# Magic Bytes — walkthrough summary

_Official Trove guide: https://trove.cyberskyline.com/fcef21cfbe47480b8eacc9f532e26803 (login required)_

## Technique

The file's magic bytes were tampered with. Inspect the header in a hex editor or CyberChef, restore the correct PNG signature bytes, repair the header, then open the image to read the flag and confirm the original file type.
