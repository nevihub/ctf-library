# Nginx

- Category: Log Analysis
- Difficulty: Medium
- Points: 100

## Description

Analyze web requests in the nginx access.log.

## Questions

- How many distinct IPs are there? (10 pts)
- How many 200 and 400 responses are there? (10 pts)
- What is the doorbell IP? (10 pts)
- What is the Googlebot version? (10 pts)
- What is the Shellshock IP? (10 pts)
- What is the top Firefox version? (10 pts)
- What are the most and second most used HTTP methods? (10 pts)
- How many requests are there for the escaped byte string? (15 pts)
