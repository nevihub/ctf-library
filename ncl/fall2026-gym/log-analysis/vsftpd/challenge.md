# VSFTPD

- Category: Log Analysis
- Difficulty: Easy
- Points: 100

## Description

Investigate FTP activity in the vsftpd.log.

## Questions

- What is ftpuser's first IP? (10 pts)
- What was the first created directory? (10 pts)
- What was the last created directory? (10 pts)
- What is the most used file extension? (10 pts)
- What is the other username? (10 pts)
- What is the other user's IP? (10 pts)
- How many bytes did the other user upload? (15 pts)
- How many bytes did ftpuser upload and download? (15 pts)
- What is the suspicious login IP? (10 pts)
