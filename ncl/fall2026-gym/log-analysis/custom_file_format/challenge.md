# Custom File Format

- Category: Log Analysis
- Difficulty: Hard
- Points: 100

## Description

Parse the custom binary log format in the .sky file.

## Questions

- What is the hostname? (10 pts)
- What is the plaintext flag? (15 pts)
- What is the creation date in UTC? (10 pts)
- How many entries are there? (10 pts)
- How many total bytes are there? (10 pts)
- How many unique IPs are there? (10 pts)
- What is the top sender IP? (10 pts)
- How many bytes did the top sender send? (10 pts)
- What was the busiest day? (15 pts)
