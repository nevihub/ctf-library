# Metadata

- Category: Scanning & Reconnaissance
- Difficulty: Hard
- Points: 100

## Description

Query the cloud instance metadata service to gather information about the instance and find the flag.

## Questions

- What is the availability zone? (20 pts)
- What is the credentials role? (20 pts)
- What is the instance type? (20 pts)
- What is the OS name and version? (20 pts)
- What is the flag? (20 pts)
