# Net Track

- Category: Scanning & Reconnaissance
- Difficulty: Medium
- Points: 100

## Description

Connect to the live network service and use its built-in commands to identify the software and retrieve files.

## Questions

- What is the software name? (25 pts)
- What is the software version? (25 pts)
- What is the flag? (25 pts)
- What is the largest file size in bytes? (25 pts)
