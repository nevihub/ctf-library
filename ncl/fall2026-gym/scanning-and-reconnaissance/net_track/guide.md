# Net Track — walkthrough summary

_Official Trove guide: https://trove.cyberskyline.com/d09ab76145a04a288729a0b87013b6c7 (login required)_

## Technique

Connect to the live target with netcat. Interact with the service using its help, version, list and get commands to identify the software name and version, list the available files to find the largest one's byte size, and retrieve the file containing the flag.

> Note: live-target challenge, no downloadable files.
