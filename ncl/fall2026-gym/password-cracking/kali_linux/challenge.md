# Kali Linux

- Category: Password Cracking
- Difficulty: Hard
- Points: 70

## Description

An /etc/shadow file was obtained from a Kali machine; the password is thought to be from Rockyou.

## Questions

- What is the username of the only account with a password? (15 pts)
- What date was the password last changed? (15 pts)
- What is the salt? (15 pts)
- What is the hash digest? (15 pts)
- What is the plaintext password? (10 pts)
