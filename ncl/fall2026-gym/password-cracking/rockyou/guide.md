# Rockyou — walkthrough summary

_Official Trove guide: https://trove.cyberskyline.com/aecdcc78aa70413aae7ea09a1b4300d4 (login required)_

## Technique

Identify the hashes as MD5 (hashcat mode 0). Decompress the rockyou wordlist and run a hashcat dictionary attack against the hashes; verify the hash ordering matches the dump. Tools: hashcat, rockyou.txt.
